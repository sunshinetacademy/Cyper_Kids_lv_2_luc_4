مقدمة: ما هو نظام التشغيل؟

نظام التشغيل (Operating System - OS) هو البرنامج الأساسي الذي يدير جميع موارد الكمبيوتر ويتحكم في كيفية تفاعل المستخدم مع الجهاز. يعتبر نظام التشغيل بمثابة "الوسيط" بين المستخدم والعتاد المادي (Hardware).

🔑 الوظائف الأساسية لنظام التشغيل:

  • إدارة الذاكرة (Memory Management): توزيع الذاكرة العشوائية (RAM) بين البرامج المختلفة
  • إدارة المعالج (CPU Management): توزيع وقت المعالج بين العمليات المختلفة
  • إدارة الملفات (File Management): تنظيم وتخزين واسترجاع الملفات
  • إدارة الأجهزة (Device Management): التحكم في الأجهزة المتصلة مثل الطابعات والشاشات
  • واجهة المستخدم (User Interface): توفير واجهة للتفاعل مع النظام

🪟 نظام Windows

🪟

ما هو Windows؟

Windows هو نظام تشغيل طورته شركة Microsoft عام 1985. يعتبر من أكثر أنظمة التشغيل استخداماً في العالم، خاصة في بيئة الأعمال والأجهزة الشخصية.

📊 إحصائيات Windows:

  • يستخدمه أكثر من 75% من أجهزة الكمبيوتر الشخصية في العالم
  • أحدث إصدار: Windows 11 (2021)
  • متوفر بنسختين: Home و Pro
  • يدعم معظم البرامج والألعاب التجارية

✅ مميزات Windows:

🎮 دعم الألعاب

دعم ممتاز لألعاب الفيديو والبرامج الترفيهية

📱 سهولة الاستخدام

واجهة مستخدم بديهية وسهلة للمبتدئين

💼 التوافق

توافق واسع مع البرامج والأجهزة المختلفة

🛠️ الدعم الفني

دعم فني متوفر من Microsoft ومجتمع كبير

⚠️ عيوب Windows من منظور أمني:

  • الاستهداف الكبير: بسبب شعبيته، يستهدفه المهاجمون بشكل أكبر
  • مصدر مغلق: الكود المصدري غير متاح للفحص العام
  • التحديثات الإجبارية: قد تسبب مشاكل في بعض الأحيان
  • التكلفة: يتطلب ترخيص مدفوع

الأمان في Windows:

# أوامر الأمان الأساسية في Windows
net user # عرض المستخدمين
net localgroup administrators # عرض المدراء
netstat -an # عرض الاتصالات النشطة
tasklist # عرض العمليات النشطة
ipconfig /all # عرض إعدادات الشبكة
sfc /scannow # فحص ملفات النظام

🐧 نظام Linux

ما هو Linux؟

Linux هو نظام تشغيل مفتوح المصدر طورته Linus Torvalds عام 1991. يعتمد على نواة Linux وهو مجاني بالكامل. يستخدم على نطاق واسع في الخوادم والأنظمة المدمجة والأجهزة المحمولة (Android).

📊 إحصائيات Linux:

  • يشغل أكثر من 90% من الخوادم في العالم
  • يستخدم في جميع أجهزة Android
  • مئات التوزيعات (Distributions) المختلفة
  • مجاني ومفتوح المصدر بالكامل

✅ مميزات Linux:

🔓 مفتوح المصدر

يمكن فحص الكود المصدري وتعديله بحرية

️ أمان عالي

نظام صلاحيات صارم ومقاوم للفيروسات

⚡ أداء عالي

خفيف على الموارد وسريع في الأداء

🎨 تخصيص كامل

يمكن تخصيص كل جانب من النظام

الأمان في Linux:

  • نظام الصلاحيات: كل ملف ومجلد له صلاحيات محددة (Read, Write, Execute)
  • المستخدم العادي: لا يمكن للمستخدم العادي تعديل ملفات النظام
  • مفتوح المصدر: يمكن فحص الكود لاكتشاف الثغرات
  • مجتمع قوي: مجتمع كبير يدعم الأمان والتحديثات

💻 أوامر Linux الأساسية:

# أوامر إدارة الملفات
ls -la # عرض الملفات مع الصلاحيات
cd /path # الانتقال لمجلد
chmod 755 file # تغيير الصلاحيات
chown user:group file # تغيير المالك

# أوامر إدارة المستخدمين
whoami # عرض المستخدم الحالي
sudo su # الانتقال للمستخدم الجذر
cat /etc/passwd # عرض المستخدمين

# أوامر الشبكة
ifconfig # عرض إعدادات الشبكة
netstat -tuln # عرض المنافذ المفتوحة
ps aux # عرض العمليات النشطة
top # مراقبة الأداء

🔐 أهمية أنظمة التشغيل في الأمن السيبراني

🎯 لماذا يجب على خبير الأمن السيبراني فهم أنظمة التشغيل؟

فهم أنظمة التشغيل هو الأساس في الأمن السيبراني. بدون فهم كيفية عمل النظام، لا يمكن حماية النظام أو اختباره.

🐧 Linux في الأمن السيبراني:

يعتبر Linux النظام الأساسي لاختبار الاختراق والأمن السيبراني. معظم أدوات الاختراق مصممة لـ Linux، وأشهر توزيعات الأمن هي:

  • Kali Linux: الأشهر لاختبار الاختراق
  • Parrot OS: بديل خفيف لـ Kali
  • BlackArch: يحتوي على آلاف الأدوات
  • Ubuntu: للاستخدام العام والتعلم

🛠️ التطبيق العملي

تمرين 1: استكشاف النظام

  • افتح Terminal في Linux أو PowerShell في Windows
  • اكتب whoami لمعرفة المستخدم الحالي
  • اكتب hostname لمعرفة اسم الجهاز
  • اكتب ipconfig (Windows) أو ifconfig (Linux) لعرض الشبكة
  • اكتب netstat -an لعرض الاتصالات النشطة

    • تمرين 2: فهم الصلاحيات (Linux)

  • اكتب ls -la لعرض الملفات مع الصلاحيات
  • افهم الصلاحيات: r (قراءة)، w (كتابة)، x (تنفيذ)
  • جرب chmod 644 file.txt لتغيير الصلاحيات
  • جرب chown user file.txt لتغيير المالك

    • 📝 تمرين 3: مراقبة النظام

  • في Linux: اكتب top لمراقبة العمليات
  • في Windows: اكتب tasklist لعرض العمليات
  • استخدم ps aux (Linux) لعرض جميع العمليات
  • استخدم netstat -tuln لعرض المنافذ المفتوحة

    ملخص المحاضرة

    ✅ النقاط الرئيسية:

    • نظام التشغيل هو البرنامج الأساسي الذي يدير الكمبيوتر
    • Windows: سهل الاستخدام، شائع، لكن مغلق المصدر
    • Linux: مفتوح المصدر، آمن، يستخدم في الخوادم والأمن السيبراني
    • فهم أنظمة التشغيل أساسي للأمن السيبراني
    • Kali Linux هو الأشهر لاختبار الاختراق
    • إتقان الأوامر (Terminal/PowerShell) ضروري
